## Описание проекта

**Code Generator** — расширение для Visual Studio Code, предназначенное для
автоматической генерации конструкций языка C++.

Плагин позволяет пользователю выбрать необходимую конструкцию и задать
параметры, после чего соответствующий фрагмент C++-кода генерируется
программно и вставляется в текущую позицию курсора.


## Возможности
- запуск генератора с помощью сочетания клавиш Ctrl + 1;
- выбор конструкции for, while или if;
- ввод параметров конструкции через интерфейс VS Code;
- программная генерация C++-кода на основе введённых параметров;
- автоматическая вставка сгенерированного кода в текущий редактор.

## Описание функций

### functions.ts

#### f_for()

- Принимает параметры цикла `for` и возвращает готовую конструкцию C++.

- Принимаемые значения:

    `type` (string): тип переменной цикла

    `variable` (string): имя переменной

    `start_val` (string): начальное значение переменной

    `condition` (string): условие продолжения цикла

    `step` (string): шаг изменения переменной

- Возвращаемое значение:

    `string`: сгенерированная конструкция `for`

- Пример вызова функции:

```typescript
f_for("int", "i", "0", "i < 10", "++i")
```

#### f_if()

- Принимает условие и возвращает готовую конструкцию `if`.

- Принимаемые значения:

    `cond` (string): условие выполнения блока `if`

- Возвращаемое значение:

    `string`: сгенерированная конструкция `if`

- Пример вызова функции:

```typescript
f_if("i > 10")
```
